# Brand and terminal styling

Keep the existing zcodetui home wordmark and theme tokens. Terminal styling
and interaction behavior follow opencode as recorded in
[Inheritance](Inheritance.md). This pass introduces no new palette,
typography, imagery or logo treatment.

The reference uses terminal text, accent category headings, flat elevated
panels and a full-row selection color. Plan status uses the existing semantic
success, warning, error and subdued colors. See [plan dialogs](01-plan-dialogs.md)
for state transitions and verification.
