## Signing

In the same pull request as your first contribution, add one line to the end
of `CLA-signatures.md`:

    Full Name <you@example.com> — YYYY-MM-DD — @your-github-username

Then sign off each commit with `git commit -s`, which appends a
`Signed-off-by:` trailer. That line plus those trailers are your signature.
There is nothing to print, scan, or email, and you only do it once.
